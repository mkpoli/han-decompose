# Components from the IDS Workshop

`Icon.svelte`, `ThemeSwitch.svelte` and `controls/Segmented.svelte`, `controls/Checkbox.svelte`,
`controls/TextField.svelte` are copied from `mkpoli/ids-input`, directories `demo/ui/` and
`demo/ui/controls/`, at commit `82c622a664eb5285ca0888504eae0bc1ef05ebca`, with their JSDoc types turned into TypeScript.
`Icon.svelte` gains the icons the viewer draws. `MenuSelect.svelte` follows the menu of
`demo/ui/SiteSelect.svelte` and `demo/ui/Menu.svelte` of the same commit, for a choice out of a list;
the viewer uses no native select.
