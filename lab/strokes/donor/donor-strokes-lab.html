Donor stroke cuts side by side

Each row is one donor character, cut by every method in the table. Every figure is the glyph's own ink: a method only decides which stroke each piece of ink belongs to, and each region is then clipped to the real outline, so they all carry the same silhouette and differ only in where the cut falls. Colours run in KanjiVG's stroke order, the same colour for the same stroke across the row. Each figure says how many strokes came out and how exactly they tile the ink.

Stroke guides from KanjiVG (Ulrich Apel, CC BY-SA 3.0); the character shapes come from Noto Sans CJK JP 2.004.
