# Licence texts

The texts of the licences the pinned fonts and sources are under, named by the identifier
`pins/fonts.json` and `pins/sources.json` give. A release carries the ones it needs.

| File | From |
|---|---|
| `OFL-1.1.txt`, `CC0-1.0.txt`, `GPL-2.0-or-later.txt`, `CC-BY-SA-3.0.txt` | SPDX license list 3.25.0, <https://github.com/spdx/license-list-data>. |
| `Arphic-1999.txt` | <http://ftp.gnu.org/non-gnu/chinese-fonts-truetype/LICENSE>, the address BabelStone Han PUA's name table gives; unaltered. |
| `MIT.txt` | The `LICENSE` of <https://github.com/yi-bai/ids> at `da1e9f8a09e2ec8faaf176bac99203f978282041`, with its copyright line. |
| `LicenseRef-BabelStone-IDS.txt` | Note 2 of the header of IDS.TXT, File Date 2025-06-27. |
| `LicenseRef-Adobe-Japan1.txt` | The notice in the README of adobe-type-tools/Adobe-Japan1 at `b42b377d7efbc233ae2a4c1833947e04760e68d1`. |
| `LicenseRef-GlyphWiki.txt` | GlyphWiki's licence page in its English translation, archived 2025-11-14. |
